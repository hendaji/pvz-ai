### Plants vs. Zombies AI — Reinforcement Learning Server

Репозиторий содержит самостоятельный проект по интеграции и обучению агента искусственного интеллекта (ИИ) для автоматического прохождения игры **Plants vs. Zombies**. 

За основу была взята готовая Python-реализация игры PvZ, в которую я спроектировал и внедрил архитектуру глубокого обучения с подкреплением (**Deep Reinforcement Learning**) на базе алгоритма **PPO (Proximal Policy Optimization)**. ИИ обучается играть «с нуля» на основе выстроенной системы наград и штрафов. 

### 🛠️ Техническая архитектура и стек

* **Core Machine Learning:** Python 3.x, PyTorch
* **RL Framework:** Gymnasium (бывший OpenAI Gym), Stable-Baselines3 (реализация PPO, MLP-политика)
* **Networking / Async:** Асинхронное взаимодействие ИИ и игры через UDP-сокеты (socket)
* **Telemetry & Logging:** TensorBoard + кастомный логгер сессий

Проект разделен на две независимые сущности: **клиент** (игра на Pygame, отправляющая состояние поля) и **сервер** (данный скрипт ИИ, обрабатывающий данные и возвращающий предсказания действий). 

### 🚀 Ключевые инженерные решения и фичи кода

### 1. Кастомная среда PureNetworkEnv (Gymnasium Wrapper)

Среда полностью написана с нуля. Она инициализирует пространство состояний и действий, а также обеспечивает обмен данными с игрой на частоте с таймаутом 0.3s: 

* **Observation Space:** Вектор из 51 признака (spaces.Box), включающий плоскую карту игрового поля (клетки), координаты/здоровье зомби и текущее количество солнца.
* **Action Space:** 91 дискретное действие (spaces.Discrete): 

  * 0 - 44: Посадка Горохострела в конкретную клетку (матрица 5х9).
  * 45 - 89: Посадка Подсолнуха в конкретную клетку.
  * 90: Действие ожидания (копление ресурсов).

### 2. Сложная функция наград (Reward Shaping)

Для предотвращения типичных багов RL-моделей (зацикливание, жадный выбор) была разработана комплексная математика вознаграждений: 

* **Защита от зацикливания:** Трекинг repeat_count штрафует модель на -30.0 за многократный спам одного и того же действия.
* **Стратегический баланс экономики:** Посадка гороха оценивается выше (+25.0), как долгосрочная инвестиция. Спам подсолнухов жестко пессимизируется (+1.0 вместо +8.0), если у ИИ уже накоплен избыток ресурсов, что заставляет его переключаться на оборону.
* **Пространственное мышление:** Матрица поля решейпится в 2D (5x9). Агент получает бонус +10.0 за равномерное покрытие всех 5 игровых линий и штрафуется за «стакинг» (выстраивание более 4 растений в одном ряду в ущерб остальным).
* **Стимуляция убийств:** Модель получает мощный импульс +40.0 за каждого уничтоженного зомби, что окупает затраты на боевые растения.

### 3. Автоматизация логирования сессий (ForceTensorBoardCallback)

Написан кастомный Callback, который автоматически сканирует директорию логов с помощью регулярных выражений, находит индекс последней сессии (PPO_1, PPO_2...) и инкрементирует его. Он форсированно отправляет в TensorBoard метрики накопленной награды за шаг и финальной награды за матч. 

### 📁 Структура репозитория в части ИИ

* ai_network_server.py — основной файл сервера (код Gymnasium среды, архитектуры PPO и цикла обучения).
* models/ — папка с чекпоинтами обучения (pvz_ppo_checkpoint_*) и финальными весами нейросети (pvz_ppo_brain_v1).
* pvz_tensorboard_logs/ — логи метрик для отслеживания сходимости ИИ.

### 💻 Инструкция по запуску

1. Клонируйте проект и установите зависимости: 

pip install gymnasium stable-baselines3 tensorboard numpy pygame

2. Запустите ИИ-сервер: 

python ai_network_server.py

3. Запустите клиент игры (скрипт или pvz.bat). Сервер автоматически подхватит соединение по адресу 127.0.0.1:5005.

*Для просмотра графиков обучения запустите:* tensorboard --logdir=./pvz_tensorboard_logs/
